# 🌐 Node.js API — Render Deployment

A lightweight Node.js REST API deployed on Render, serving as the backend for the Todo React application.

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express
- **Deployment:** Render

## 🚀 Run Locally

```bash
npm install
npm start
```
